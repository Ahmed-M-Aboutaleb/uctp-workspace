# Local Search Strategies

In the proposed MA, after an initial solution or a new offspring solution is created, two local search (LS) operators are applied sequentially. These two LS strategies are based on three neighbourhood structures: N1, N2, and N3.

- N1: the neighbourhood defined by an operator that moves one event from a time slot to a different one.
- N2: the neighbourhood defined by an operator that swaps the time slots of two events.
- N3: the neighbourhood defined by an operator that permutes three events in three distinct time slots in one of the two possible ways other than the existing permutation of the three events.

## 4.2.1.1 LS Strategy 1 (LS1)

Algorithm 8 shows the pseudo-code of LS1. LS1 works on all events of an individual. Here, we assume that each event may be involved in soft and hard constraint violations.

LS1 operates in two steps.

In the first step (lines 3-13 in Algorithm 8), LS1 checks hard-constraint violations for each event while ignoring soft-constraint violations. If an event has hard-constraint violations, LS1 tries to resolve them by applying moves in neighbourhoods N1, N2, and N3 in order until a termination condition is reached, for example:

- improvement is found, or
- the maximum number of steps `smax` is reached.

The value of `smax` is set differently for different problem instances. After each move, the matching algorithm is applied to the affected time slots to resolve room-allocation disturbance, and the move is delta-evaluated (hard and soft violations before and after the move).

If there is no untried move left in the neighbourhood for an event, LS1 continues to the next event. After applying neighbourhood moves to each event, if any hard-constraint violation remains, LS1 stops. Otherwise, LS1 performs the second step (lines 17-27 in Algorithm 8).

In the second step, after reaching a feasible solution, LS1 deals with soft constraints and performs a process similar to the first step on each event to reduce soft-constraint violations. For each event, LS1 tries moves in N1, N2, and N3 in order without violating hard constraints. For each move, the matching algorithm allocates rooms to affected events and the move is delta-evaluated.

When LS1 finishes, we obtain a possibly improved and feasible individual. LS2 is then applied to this individual.

## 4.2.1.2 LS Strategy 2 (LS2)

Algorithm 9 shows the pseudo-code of LS2. The basic idea of LS2 is to choose a high-penalty time slot that may contain many events involved in hard and soft constraint violations.

LS2 first randomly selects a `tp` percentage of time slots from the total set of time slots `T`. Rather than selecting the worst time slot from all time slots, LS2 randomly selects a subset and then picks the worst one within that subset. This reduces computation time, because penalty values must be calculated for examined time slots.

Then LS2 computes the penalty of each selected time slot and chooses the worst time slot `wt` (the one with the largest penalty) for LS operations. In this way, LS2 aims to improve the result produced by LS1.

After selecting `wt`, LS2 tries an N1 move for each event in `wt`, and checks each event's penalty value before and after the move. If all moves in `wt` together reduce hard and/or soft constraint violations, LS2 applies all moves; otherwise, it discards them.

This allows LS2 not only to examine the worst time slot but also to reduce penalties for some events by moving them to other time slots. In general, LS2 can enhance individuals in the population and improve feasible timetable quality by reducing constraint violations.


```text
Algorithm 8 Local Search Strategy 1 (LS1)
1: input : Individual I selected from the population
2: while Termination condition not reached do
3:    for i = 1 to the total number of events do
4:        if event i is infeasible then
5:            if there is untried move left then
6:              calculate the next move (first in N1, then in N2, and finally in N3)
7:              apply the matching algorithm to the time slots affected by the move and delta-evaluate the result.
8:              if the move reduces hard constraint violation then
9:                make the move
10:             end if
11:         end if
12:       end if
13:     end for
14:   if any hard constraint violations remain then
15:     terminate LS1
16:   else
17:     for i = 1 to total number of events do
18:       if event i has soft constraint violation then
19:         if there is untried move left then
20:           calculate the next move (first in N1, then in N2, and finally in N3)
21:           apply the matching algorithm to the time slots affected by the move and delta-evaluate the result
22:           if the move reduces soft constraints violation then
23:             make the move
24:           end if
25:         end if
26:       end if
27:     end for
28:   end if
29: end while
30: output : A possibly improved individual I
```

**Note 1:** For the event being considered, potential moves are calculated in a strict order. First, we try to move the event to the next time slot, then the next, and so on. If this search in N1 fails, we search in N2 by trying to swap the event with the next event in the list, then the next, and so on. If the search in N2 also fails, we try a move in N3 by using one different permutation formed by the event with the next two events, then with the following two, and so on.

```text
Algorithm 9 Local Search Strategy 2 (LS2)
1: input : Individual I after LS1 is applied
2: S := randomly select a tp percentage of time slots from the total time slots of T
3: for each time slot ti ∈ S do
4:    for each event j in time slot ti do
5:      calculate the penalty value of event j
6:    end for
7:    sum the total penalty value of events in time slot ti
8: end for
9: select the time slot wt with the biggest penalty value from S
10: for each event i in wt do
11:     calculate a move of event i in the neighbourhood structure N1
12:     apply the matching algorithm to the time slots affected by the move
13:     compute the penalty of event i and delta-evaluate the result
14: end for
15: if all the moves together reduce hard or soft constraint violations then
16:   apply the moves
17: else
18:   delete the moves
19: end if
20: output : A possibly improved individual I
```
